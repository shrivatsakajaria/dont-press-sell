## How sure an expert is, from the blind headlines alone

A separate tester with deep market-history knowledge read each run's blind headlines in order and guessed the episode. Single lines that gave the year away on their own were rewritten. Taken all together, the order of events still lets an expert name most runs:

| Run | Expert's confidence (all lines together) |
|---|--:|
| 1929: the Wall Street Crash | 97% |
| 1987: Black Monday | 97% |
| 2000: the dot-com crash | 97% |
| 2008: the financial crisis | 99% |
| 2020: Covid | 99% |
| 2022: inflation and interest rates | 99% |
| Summer 1998 Russia scare | 95% |
| 2011 debt downgrade scare | 97% |
| Autumn 2014 wobble | 92% |
| Autumn 2018 wobble | 97% |
| Summer 2024 wobble | 80% |
| Spring 2025 tariff scare | 97% |

Measured before the final rewrites for the ten original runs, so these figures are, if anything, high. A casual player will be far less sure; a market-history fan will often recognise big crashes by the middle of the run. Options if this bothers you: (a) accept it (my recommendation: by the time the famous events arrive, the hold-or-sell bet is already live), (b) show fewer, vaguer news lines in mystery runs.

## Flags nobody could settle

None open. Every line has two independent sources, every date follows the after-the-close and weekend rule, and every market claim matches the day's real move. 17 lines were dropped where a date or timing could not be confirmed.
